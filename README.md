# the-snake
Учебная игра "Змейка" на Python при использовании фреймворка Pygame. 
Реализована на основе шаблона репозитория the-snake

Запуск: 
- из папки проекта выполнить: 
```
python -m venv venv
source venv/bin/activate
python -m pip install -r requirements.txt
python the_snake.py 
```

Управление игрой происходит стрелками.

Реализована система меню с возможностью выйти из игры, начать игру и изменить скорость игры.
